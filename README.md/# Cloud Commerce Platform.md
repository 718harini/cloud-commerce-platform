# Cloud Commerce Platform

A hands-on project to learn Python, Flask, MySQL, Git, GitHub, AWS, and DevOps.

## Project Structure

* `frontend/` — Website interface
* `backend/` — Python Flask application and APIs
* `database/` — Database scripts and structure

## Project Goals

* Build a web application.
* Develop backend APIs using Python and Flask.
* Connect the application to a MySQL database.
* Learn Git and GitHub version control.
* Deploy the application on AWS.
* Practice DevOps concepts and tools.
